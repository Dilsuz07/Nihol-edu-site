📖 Soddalashtirilgan Darslar

Oson tilda tushuntirilgan matematik mavzular

1. Kvadrat Tenglamalar Asoslari

Kvadrat tenglama - bu ax² + bx + c = 0 ko'rinishidagi tenglama.

Oddiy misol: x² - 5x + 6 = 0

Yechim:
1) Diskriminantni topamiz: D = b² - 4ac = 25 - 24 = 1
2) Ildizlar: x₁ = 2, x₂ = 3

2. Ko'paytirish Formulalari

Qisqa ko'paytirish formulalari - bu tez hisoblash uchun maxsus formulalar.

Asosiy formulalar:
• (a + b)² = a² + 2ab + b²
• (a - b)² = a² - 2ab + b²
• (a + b)(a - b) = a² - b²

Misol:
(5 + 3)² = 25 + 30 + 9 = 64

3. Kasrlar bilan Ishlash

Kasrlarni qo'shish, ayirish, ko'paytirish va bo'lish - oddiy qoidalar.

Qo'shish:
1/2 + 1/3 = 3/6 + 2/6 = 5/6

Ko'paytirish:
2/3 × 3/4 = 6/12 = 1/2

4. Foizlar

Foiz - bu 100 dan bir qism. % belgisi bilan belgilanadi.

Misol 1:
200 ning 25% ini toping
Yechim: 200 × 25/100 = 50

Misol 2:
50 soni 200 ning necha foizi?
Yechim: 50/200 × 100 = 25%

5. Perimetr va Yuz

Geometrik shakllarning perimetri va yuzini hisoblash.

To'rtburchak:
Perimetr: P = 2(a + b)
Yuz: S = a × b

Misol:
a = 5, b = 3
P = 2(5 + 3) = 16
S = 5 × 3 = 15

6. Proporsiya

Proporsiya - bu ikki nisbatning tengligi.

a/b = c/d formulasi

Misol:
2/3 = x/6
Yechim: x = (2 × 6) / 3 = 4
